# Referensi Desain Logo FinZen

## 1. Konsep & Makna

**FinZen** = **Fin**ancial + **Zen** (ketenangan, keseimbangan)

Logo harus mencerminkan:
- **Ketenangan finansial** - Pengelolaan keuangan yang tenang dan terkontrol
- **Konsistensi** - Streak system dan kebiasaan finansial yang berkelanjutan
- **Modern & Fresh** - Sesuai dengan target Gen Z
- **Simpel & Memorable** - Mudah diingat dan dikenali

## 3. Konsep Desain Logo

### 3.1 Opsi 1: Simbol Zen + Finansial (RECOMMENDED)
**Konsep**: Kombinasi simbol zen (lingkaran/meditasi) dengan elemen finansial

**Elemen**:
- **Lingkaran** (simbol zen, keseimbangan, kelengkapan)
- **Garis naik** di dalam lingkaran (tren finansial positif, growth)
- **Titik** di tengah (fokus, konsistensi)

**Makna**:
- Lingkaran = Keseimbangan finansial, siklus yang konsisten
- Garis naik = Pertumbuhan finansial, progress positif
- Titik = Fokus pada tujuan, konsistensi harian

**Warna**:
- Primary: Biru (#3B82F6) atau Hijau (#22C55E)
- Variasi: Gradient dari Biru ke Hijau (pertumbuhan)

### 3.2 Opsi 2: Huruf "F" Stylized
**Konsep**: Huruf "F" yang disederhanakan dengan elemen zen

**Elemen**:
- Huruf "F" dengan sudut melengkung (soft, friendly)
- Garis horizontal di bagian bawah membentuk panah naik
- Minimalis, modern

**Makna**:
- "F" = FinZen, Financial
- Panah naik = Progress, growth
- Bentuk melengkung = Friendly, approachable untuk Gen Z

**Warna**:
- Primary: Gradient Biru-Ungu (#3B82F6 → #A855F7)
- Atau solid: Biru (#3B82F6)

### 3.3 Opsi 3: Icon Streak + Circle
**Konsep**: Menggabungkan konsep streak (api) dengan lingkaran zen

**Elemen**:
- Lingkaran dengan api kecil di dalam (streak system)
- Atau lingkaran dengan titik-titik yang membentuk pola (konsistensi)

**Makna**:
- Streak = Konsistensi harian, kebiasaan finansial
- Lingkaran = Keseimbangan, zen
- Kombinasi = Finansial yang konsisten dan seimbang

**Warna**:
- Primary: Kuning-Orange (#EAB308 → #EF4444) untuk api
- Atau: Biru dengan aksen kuning

## 4. Spesifikasi Teknis

### 4.1 Dimensi & Format
```
Format: SVG (scalable) + PNG (untuk fallback)
Rasio: 1:1 (square) atau 4:3 (landscape)
Ukuran Minimum: 64x64px
Ukuran Recommended: 512x512px
Ukuran Maksimal: 1024x1024px
```

### 4.2 Background
**Light Mode**:
- Background: Putih (#FFFFFF) atau transparan
- Logo: Warna solid atau gradient

**Dark Mode**:
- Background: Hitam (#0A0A0A) atau transparan
- Logo: Warna lebih terang atau versi inversi

**Transparan (Recommended)**:
- Logo dengan background transparan
- Dapat digunakan di berbagai background

### 4.3 Typography (Jika ada teks)
```
Font: Geist Sans (sesuai aplikasi)
Weight: Medium (500) atau Semi-Bold (600)
Size: Proporsional dengan icon
Spacing: Letter-spacing 0.02em untuk "FinZen"
```

## 5. Variasi Logo

### 5.1 Logo Utama (Full Logo)
- Icon + Teks "FinZen"
- Horizontal layout

- Hanya icon/simbol

- Icon di atas, teks di bawah

- Untuk watermark, dokumen hitam putih

## 8. Guidelines Penggunaan

### 8.1 Spacing
- Minimum clear space: 1x tinggi logo
- Jangan letakkan elemen lain terlalu dekat

### 8.2 Ukuran Minimum
- Icon only: 24x24px
- Full logo: 120x40px (horizontal) atau 80x80px (stacked)

### 8.3 Jangan Lakukan
- ❌ Jangan skew atau distort logo
- ❌ Jangan ubah proporsi warna
- ❌ Jangan tambahkan efek yang tidak perlu (shadow, glow berlebihan)
- ❌ Jangan gunakan warna yang tidak ada di palet

### 8.4 Do's
- ✅ Gunakan versi yang sesuai dengan background
- ✅ Pertahankan rasio aspek
- ✅ Gunakan format SVG untuk kualitas terbaik
- ✅ Test di berbagai ukuran dan background

## 9. Implementasi di Aplikasi

### 9.1 Lokasi Penggunaan
1. **Favicon** (`/favicon.ico`) - 32x32px atau 16x16px
2. **App Icon** - 192x192px, 512x512px (PWA)
3. **Header/Navbar** - 40-48px tinggi
4. **Sidebar** - 32-40px tinggi
5. **Loading Screen** - 120x120px
6. **Social Media** - 1024x1024px (untuk cover/profile)

### 9.2 File yang Dibutuhkan
```
public/
├── logo.svg              (SVG utama, transparan)
├── logo-light.svg        (Versi untuk light mode)
├── logo-dark.svg         (Versi untuk dark mode)
├── logo-icon.svg         (Icon only)
├── favicon.ico           (Favicon)
├── apple-touch-icon.png  (iOS icon, 180x180px)
└── android-chrome.png    (Android icon, 192x192px)
```

## 10. Inspirasi & Referensi

### 10.1 Aplikasi Finansial Modern
- **Mint**: Hijau, simple, friendly
- **YNAB**: Biru, professional, clean
- **PocketGuard**: Orange, energetic, modern

### 10.2 Aplikasi Zen/Wellness
- **Headspace**: Orange, friendly, approachable
- **Calm**: Biru, peaceful, minimal

### 10.3 Prinsip Desain
- **Simplicity**: Logo harus mudah dikenali dalam ukuran kecil
- **Scalability**: Harus terlihat bagus dari 16px hingga 1024px
- **Memorability**: Unik dan mudah diingat
- **Relevance**: Mencerminkan nilai dan tujuan aplikasi

## 11. Checklist Final

Sebelum finalisasi logo, pastikan:
- [ ] Logo terlihat jelas di ukuran kecil (24x24px)
- [ ] Logo terlihat bagus di light dan dark mode
- [ ] Logo dapat digunakan dengan background transparan
- [ ] Warna sesuai dengan palet aplikasi
- [ ] Logo mencerminkan makna "FinZen" (Financial + Zen)
- [ ] Logo modern dan sesuai target Gen Z
- [ ] Logo simple dan memorable
- [ ] Format SVG tersedia untuk kualitas terbaik
